## Tagline

Open-source .NET and Python foundations for data, media, and developer automation.

## Description

RAIkeep is an Apache-2.0 framework of .NET and Python libraries and CLIs for historical JSON storage, cloud-backed files, images, diagrams, and code guardrails. It runs on Windows, macOS, and Linux, with packages published on NuGet and PyPI.

## Reputation

OsLib and JsonPit have public GitHub histories dating to March 2019. NuGet reports 45,793 cumulative downloads for OsLibCore and 13,860 for JsonPit as of November 18, 2026. Over the preceding 30 days, their repositories received 17 and 21 commits respectively. The suite has public source, tests, GitHub Actions builds, and coordinated releases.

## URL choices

The umbrella repository is the homepage. The proposed Download URL links all
active packages and carries the SignPath application notice on the same page.
An individual NuGet package page also provides downloads, but its published
README would need the signing-policy notice for the form's stated requirement.

The privacy-policy text in README_codesigning.md is a local proposal. The form allows
an empty Privacy Policy URL when the software does not collect user data.
RAIkeep processes user-selected application data and configured cloud files;
that behavior is described in the proposed policy. Review and publish it before
using its public URL. Leave the Wikipedia field empty.
