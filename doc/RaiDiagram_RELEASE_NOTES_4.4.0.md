# RaiDiagram 4.4.0 Release Notes

RaiDiagram 4.4.0 implements the reusable model and SVG portions of accepted
[`CR036_AIA_to_RAIkeep_Raid_CLI.md`](https://github.com/Burkhardt/RAIkeep/blob/main/doc/CR036_AIA_to_RAIkeep_Raid_CLI.md).

It adds `IModelImporter`, `PlantUmlModelImporter`, `RaidDiagramModel`, typed
canvas presentation geometry, and `AimSvg` emission/validation. Activity
conditionals, forks, swimlane facts, class/interface members, generalization,
association, composition, and aggregation are covered by deterministic tests.
