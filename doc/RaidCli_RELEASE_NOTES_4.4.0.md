# RaidCli 4.4.0 Release Notes

RaidCli 4.4.0 is the new first-class CLI requested by accepted
[`CR036_AIA_to_RAIkeep_Raid_CLI.md`](https://github.com/Burkhardt/RAIkeep/blob/main/doc/CR036_AIA_to_RAIkeep_Raid_CLI.md).

The NuGet tool package installs `raid`. It supports PlantUML import to `.raid`
and `aim-*` SVG, validation of both artifact types, deterministic `--name`
overrides, and synchronized `raid --version` output of `4.4.0`.
