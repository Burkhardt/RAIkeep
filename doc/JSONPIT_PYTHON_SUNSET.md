# JsonPit.Python sunset

The legacy [jsonpit-python repository](https://github.com/Burkhardt/jsonpit-python)
is archived. The final implementation release is tag `v4.6.3`, commit
`a8175618ae915363b6c59705dd061ca2feed03f3`. The later PyPI `4.6.3.post1`
distribution contains only the sunset notice.

To inspect the frozen source:

```sh
git clone https://github.com/Burkhardt/jsonpit-python.git
git -C jsonpit-python checkout --detach v4.6.3
```

Use `umgodi-json` for ongoing Python development.
