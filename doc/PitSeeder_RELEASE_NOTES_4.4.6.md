# Release Notes: PitSeeder v4.4.6

Adds explicit `pits seed <PitName> --source -` ingestion and whole-batch live-ID preflight before writable Pit creation. Typed OsLib callers can provide buffered standard input. Reports `pits v4.4.6`.

This is part of the coordinated nine-package [CR049](CR/CR049_AIA_and_jsonpit_to_RAIkeep_Live-ID-Validation_and_Zip-Image-Import.md) release. Package versions and fallback dependencies align at 4.4.6.
